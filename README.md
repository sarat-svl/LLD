# Low-Level Design

This repository collects low-level design projects. Each project is maintained
in its own Git repository and included here as a Git submodule.

## Projects

- [Splitwise](./splitwise/README.md) — group expense sharing, balance tracking,
  and debt simplification.

## Clone

Clone this repository and its project submodules with:

```sh
git clone --recurse-submodules https://github.com/sarat-svl/LLD.git
```

If you already cloned without submodules, initialize them with:

```sh
git submodule update --init --recursive
```
